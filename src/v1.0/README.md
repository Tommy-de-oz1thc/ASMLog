# ASMLog v1.0

ASMLog v1.0 is the first official free release of ASMLog.

ASMLog is an amateur radio logging program written in NASM x64 Assembly for Windows.

## Supported logs and contests

ASMLog v1.0 supports:

- HF Log
- CQ WPX CW Contest
- ARRL DX CW Contest
- Russian DX Contest
- CQ WW DX CW Contest
- Scandinavian Activity Contest (SAC CW)

## Features

### HF Log

- QSO logging
- Callsign search
- ADIF export
- Name and QTH fields

### Contest logging

- QSO logging
- Duplicate QSO checking
- Contest scoring
- Multiplier handling
- Cabrillo export

### Settings

ASMLog stores settings for:

- Log type
- Callsign
- Name
- E-mail
- Address
- Postal code
- City
- Power category
- ARRL DX power in watts

Settings are saved and restored when ASMLog is restarted.

## Source code

The source code for ASMLog v1.0 is located in the `ASM` directory.

ASMLog is written in NASM x64 Assembly.

The included `build.bat` is used to build the program on Windows.
